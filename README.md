# FFmpeg Studio

**一个把 FFmpeg 装进图形界面的桌面工具**——不用记命令行，点几下就能完成视频格式转换、压缩、剪辑、加水印、做动图等常见音视频处理。所有操作都在你自己的电脑上本地完成，文件不会上传到任何服务器。

> 适用人群：想把视频/音频处理好的普通用户，不需要会写代码或命令。

---

## 一、它能做什么

左侧导航（或工作台「快速开始」）里的每一项都是一个独立工具：

| 工具 | 用来做什么 | 常用场景 |
|---|---|---|
| **格式转换** | 把视频/音频换成另一种容器或编码 | MP4 转 MKV、MOV 转 MP4、WAV 转 MP3 |
| **压缩优化** | 在尽量不损画质的前提下减小体积 | 发微信/邮件前压一压大视频 |
| **剪辑分割** | 按时间精确截取一段，或按段拆分 | 剪掉片头片尾、把长视频切成几段 |
| **拼接合并** | 把多个文件按顺序合成为一个 | 合并分集视频、拼接多个片段 |
| **提取分离** | 抽出音轨、抽单帧图片、生成缩略图 | 只要背景音乐、截取某帧做封面 |
| **水印字幕** | 加图片/文字水印、烧录硬字幕、**消除水印** | 加 logo、给视频配字幕、去掉台标 |
| **滤镜调色** | 旋转/裁剪/缩放/调色/降噪等叠加滤镜 | 竖屏转正、调亮度对比度、去噪 |
| **音频处理** | 转码、调音量、响度归一、**降噪**、多段拼接 | 降环境底噪、统一几段音频音量 |
| **动图 GIF** | 把视频片段做成 GIF（画质更干净） | 做个表情包、教程动图 |
| **媒体信息** | 查看时长/分辨率/编码/码率等元数据（支持 A/B 对比） | 先看清楚文件参数再处理 |
| **录制采集** | 录屏幕、录摄像头、画中画 | 录屏做教程 |
| **流媒体** | RTMP / HLS 推流与拉流录制 | 直播推流、抓取网络流 |
| **批量处理** | 对整个文件夹批量转换/压缩 | 一次性处理一堆文件 |

另有 **任务队列**（看运行进度与历史）和 **设置**（配置引擎与默认项）。

## 二、系统要求

- **操作系统**：桌面端，Windows 为主（已适配；macOS / Linux 也可从源码构建）。
- **必须额外安装 FFmpeg**：本工具本身不内置 FFmpeg，它调用你电脑上已安装的 FFmpeg 来干活。
  - 建议安装 **FFmpeg 7.x**（部分功能如「消除水印」需要较新版本）。
  - 把 FFmpeg 的 `bin` 目录加到系统的 **PATH** 环境变量，最简单的办法；
    或者不配 PATH，直接在「设置」里填 FFmpeg 可执行文件的**完整路径**。

## 三、安装与首次配置

### 方式一：下载安装包（推荐，等发布后）
从项目的发布页下载对应系统的安装包，双击安装即可。

### 方式二：从源码构建（开发者向，见文末「进阶」）

### 首次打开请做两件事
1. 打开左下角齿轮 **设置** → **FFmpeg 引擎**，确认 FFmpeg 路径正确（留空表示用 PATH 里的 `ffmpeg`）。
2. 点一下「检测版本」，能显示出版本号就说明配置成功；若提示找不到，请检查 PATH 或重新填写路径。

> ⚠️ 如果没配好 FFmpeg，所有处理都会失败并提示「无法执行 ffmpeg」。

## 四、三步上手（通用流程）

几乎每个工具都用同一套流程：

1. **选源文件**：在工作台或各工具页把文件**拖进来**，或点「选择文件」按钮。
   - 选好后界面会显示出文件名、时长、分辨率等基本信息。
2. **调参数**：按你的需要设置选项（页面下方会**实时预览将要执行的 FFmpeg 命令**，看不懂也没关系，它只是给你确认用）。
3. **运行**：点「运行 / 开始」，**输出文件默认保存在源文件所在的同一个文件夹里**，文件名会自动加上后缀（如 `.watermarked`、`.delogoed`）以免覆盖原片。

> 处理大文件时，底部会显示进度。想同时跑多个任务，可切到 **任务队列** 查看。

## 五、各功能使用要点

下面只讲每个工具最值得注意的地方，具体选项在界面上都有中文说明。

- **格式转换 / 压缩优化**：可开启「硬件加速」（见下方技巧）。压缩时主要调 **CRF**（数值越小画质越好、体积越大，默认 23）。
- **剪辑分割**：
  - 选「重新编码」可精确到任意时间点；选「关键帧快剪」速度极快但只能切在关键帧上。
  - 支持按固定时长或固定段数把长视频自动拆成多段。
- **拼接合并**：「流拼接」几乎无损且快，但要求各文件编码一致；不一致时用「滤镜拼接」（会重编码）。
- **提取分离**：可只抽声音、只抽画面、抽某一帧图片，或生成封面缩略图。
- **水印字幕**：
  - 图片水印可调大小、位置、透明度；文字水印可调内容、字体、颜色。
  - **消除水印**：在预览画面里**拖拽框选**要消除的区域（也能直接填坐标），建议先开「显示绿框」跑几秒确认框得准，再正式处理。
- **滤镜调色**：多个滤镜可叠加成一条链（旋转→裁剪→调色→降噪等）。
- **音频处理**：
  - 「降噪」有两种算法：`FFT 降噪` 适合电流/风扇等稳态噪声且速度快；`非局部均值` 更自然但**慢很多**，只建议处理几分钟以内的音频。
  - 支持多段音频按顺序拼接。
- **动图 GIF**：
  - **这个页面最该先看源时长**——它会实时显示总时长。
  - 不限时长、或片段太长时，页面会**预估体积并给出告警**（GIF 很容易几十上百 MB），建议缩短时长、降低帧率或宽度。
  - 可调整「颜色数」和「抖动算法」来平衡画质与体积。
- **媒体信息**：可同时载入两个文件做 A/B 对比，查看编码、码率、帧率、分辨率、声道等详细参数。

## 六、通用技巧与说明

- **硬件加速**：在支持的页面可勾选用显卡编码（NVENC / AMF / QSV），速度通常远快于纯 CPU。
  - 前提是你电脑装有对应显卡与驱动；若选了却报错「找不到编码器/驱动」，说明该硬件加速在本机不可用，关掉即可回退到软件编码。
  - 注意：WebM / GIF / 纯音频等场景用不上硬件加速，界面会自动禁用。
- **输出位置**：默认落在源文件同目录，文件名带后缀，不会覆盖原片。录制/拉流没有本地源文件时，会存到系统的「视频」文件夹。
- **覆盖提示**：可在「设置」里决定是否覆盖已存在的输出文件。
- **暗色 / 亮色**：右上角或设置里切换主题，下次启动记住你的选择。

## 七、常见问题

| 现象 | 可能原因 / 解决办法 |
|---|---|
| 一点运行就报「无法执行 ffmpeg」 | FFmpeg 没装，或路径没配好。去「设置 → FFmpeg 引擎」检测版本确认。 |
| 提示某编码器不存在 / 不支持 | 你选了当前 FFmpeg 不支持的编码（如硬件加速不可用、或 WebM 选了不兼容的编码器）。换软件编码或换容器。 |
| 硬件加速选了却失败 | 本机缺对应显卡驱动。关掉硬件加速，用 CPU 编码即可。 |
| 做出的 GIF 特别大 | 片段太长 / 帧率太高 / 分辨率太大。按页面告警缩短时长、降帧率或降宽度。 |
| 文字水印显示成空白 | 字体路径问题。确认系统有该字体，或换用图片水印。 |
| 消除水印框选后报错 | 框超出了画面范围。把框缩到画面内即可。 |

## 九、进阶：从源码构建

> 这一段主要给开发者，普通用户可忽略。

需要本机已安装 [Node.js](https://nodejs.org) 与 [Rust 工具链](https://www.rust-lang.org)，以及 FFmpeg。

```bash
# 1. 安装前端依赖
npm install

# 2. 以桌面应用方式开发预览（会自动编译 Rust 后端并启动窗口）
npm run tauri dev

# 3. 打包成安装程序
npm run tauri build
```

- 配置见 `src-tauri/tauri.conf.json`（窗口尺寸、深色底色等）。
- 前端源码在 `src/`，Rust 后端在 `src-tauri/src/`。
- 界面功能模块清单集中在 `src/nav.ts`，新增功能只需改这一处。
